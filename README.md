# Fox Coffee

Статический одностраничный сайт для GitHub Pages. Три сцены: атмосфера кофейни, кофе и десерты. Фото сгенерированы специально для проекта; изображения хранятся локально в `assets/`.

## Посмотреть локально

Откройте `index.html` в браузере. Для просмотра через локальный сервер выполните `python -m http.server 8000` в папке проекта и откройте `http://localhost:8000`.

## Опубликовать на GitHub Pages

1. Загрузите `index.html`, `styles.css`, `app.js`, `.nojekyll` и папку `assets` в корень репозитория.
2. В репозитории откройте Settings → Pages.
3. Выберите Deploy from a branch, ветку с файлами сайта и папку `/ (root)`, затем Save.

Пути относительные: сайт работает и в корне домена, и по адресу проекта вида `username.github.io/repository/`. Сборка, API и ключи не требуются.

## Изменить содержимое

Название, адрес, часы, ассортимент и цены — в `index.html`. Описания выбранных позиций — в `app.js`, объект `notes`; отдельные фото и их описания — объект `products`. Цвета и адаптивная вёрстка — в `styles.css`. Цены и ассортимент демонстрационные.

Каждому напитку и десерту соответствует собственная фотография одного продукта. При выборе снимок плавно меняется. У айс-латте пар отключён. На первой сцене полупрозрачные струйки пара привязаны к обеим чашкам, учитывают кадрирование фотографии и усиливаются при прокрутке. При отключении анимации пар не рисуется.

Прокрутка управляет отдельными сценами: предыдущая полностью затухает перед появлением следующей. Кнопки навигации позволяют сразу перейти к разделу. Анимация учитывает системную настройку уменьшения движения и отключается кнопкой. Без JavaScript сцены отображаются последовательно.
