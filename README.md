# Fox Coffee · версия 2

Статический лендинг для GitHub Pages: атмосфера кофейни, кофе и десерты. Меню включает 9 напитков, 6 десертов и 3 готовых сочетания. Ассортимент, рецепты и цены демонстрационные.

## Посмотреть

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны. Также можно запустить `python -m http.server 8000` в папке сайта и открыть `http://localhost:8000`.

## Новая версия

- Светлая кремовая палитра, зелёные акценты, карточки и категории меню.
- 15 новых фотографий: один продукт на каждом снимке, единый свет и фон. Оптимизированные WebP находятся в `assets/v2/`, описания генерации — в `assets/v2/GENERATION.md`.
- У каждой позиции есть описание вкуса, объём или вес, цена, раскрывающиеся состав и аллергены.
- Рекомендованная пара открывает соответствующий продукт в соседнем разделе.
- «Утро в Fox», «Сладкая пауза» и «Время вдвоём» открываются в отдельном окне. Стоимость вычисляется из цен позиций без дополнительной скидки.
- Ссылка на карту, адрес и часы работы. Телефон не указан.

## Управление

На компьютере прокрутка переключает сцены: предыдущая полностью затухает перед появлением следующей. Расширенное содержимое меню при необходимости прокручивается внутри панели; затем прокрутка продолжается между сценами.

До 760 пикселей короткий свайп влево открывает следующий раздел, вправо — предыдущий. Вертикальный жест прокручивает подробности текущего меню. Крупное фото расположено сверху; нажатие на карточку возвращает к нему. Нижняя навигация всегда доступна. Свайпы у края экрана не перехватываются, масштабирование двумя пальцами разрешено. Выбор продукта сохраняется при возвращении.

Пар привязан к чашкам в первой сцене и усиливается при прокрутке. Системная настройка уменьшения движения и кнопка анимации отключают эффекты. Окно сочетаний закрывается крестиком, Escape или нажатием на фон. Есть клавиатурная навигация и подписи элементов. Без JavaScript показываются три статических раздела с начальными позициями.

## Где менять данные

- `menu-data.js` — категории, названия, цены, объём/вес, описания, состав, аллергены, фото, рекомендации и сочетания. Суммы сочетаний рассчитываются автоматически.
- `index.html` — основные тексты, адрес, часы, ссылки и начальное содержимое до загрузки JavaScript. При изменении количества позиций обновите счётчики в приветствии и подзаголовках.
- `v2.css` — оформление новой версии поверх базового `styles.css`.
- `app.js` — навигация, выбор продуктов, сочетания, жесты, пар и эффекты.

## GitHub Pages

В корне публикации должны находиться `index.html`, `styles.css`, `v2.css`, `menu-data.js`, `app.js`, `.nojekyll` и папка `assets/`. Все внутренние пути относительные: поддерживается адрес проекта вида `username.github.io/repository/`. API, ключи и серверная часть не нужны.

В Settings → Pages выберите Deploy from a branch, нужную ветку и папку / (root). Папка `preview/` и ZIP-архивы не входят в репозиторий.
